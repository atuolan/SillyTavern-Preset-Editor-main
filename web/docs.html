项目使用与介绍

定位

本工具用于导入酒馆（SillyTavern）预设，进行可视化编辑，并按规则导出提示词、预设 JSON 与正则脚本。

基础操作流程

  1. 在主页面导入酒馆预设 JSON，或点击“新建工程”。
  2. 按需新增配置组、修改配置组ID，或在双重确认后删除配置组。
  3. 在“提示词”页进行增删改、启用控制和顺序调整。
  4. 在“正则”页编辑脚本并勾选要导出的脚本。
  5. 在“API 配置”页按需修改参数（默认不会写入导出 JSON）。
  6. 导出时默认选 `TXT`；需要回酒馆时改选 `JSON`。

导出规则速览

  • `TXT`：仅提示词内容，默认不携带正则与 API 配置。
  • `JSON`：酒馆风格预设，可选“全部提示词 / 仅启用提示词”。
  • 勾选“JSON 携带正则”时，仅会打包正则页中已选中的脚本。
  • 正则独立导出始终为“一脚本一文件”的 JSON 结构。
预设变量（酒馆宏）

以下是常见宏示例。可用宏集合会因上下文和版本变化，请以官方文档为准。

变量 说明
{{char}} 当前角色名
{{user}} 当前用户名
{{group}} 群聊名称（群聊上下文）
{{lastMessage}} 最近一条消息文本
{{lastUserMessage}} 最近一条用户消息文本
{{time}} 当前时间
{{date}} 当前日期
正则配置说明
字段 说明
id 脚本唯一标识
scriptName 脚本显示名
findRegex 匹配表达式（通常写为 /pattern/flags）
replaceString 替换文本
trimStrings 替换前后额外裁剪的字符串数组
placement 执行位置数组（酒馆内部枚举值）
disabled 是否禁用
markdownOnly 仅在 Markdown 文本场景执行
promptOnly 仅在提示词拼装阶段执行
runOnEdit 编辑阶段即时执行
minDepth / maxDepth 按对话层数限制生效范围（可为 null）

本工具导出正则时保持“每个脚本一个 JSON 文件”，不做额外包裹。
